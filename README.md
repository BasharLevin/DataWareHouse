# DataWareHouse
Data warehouse project for AW Academy Week 4 (16.-20.11.2026).

## Project task:
Design and implement an operational database for a light transport equipment
rental company. Design and implement a simple data warehouse from the operational data, create SQL-based ETL scripts, validate the data warehouse with SQL queries, and build Power BI reports from the data warehouse.

The company rents light transport equipment in several countries and major cities. Rental equipment can include electric bicycles, scooters, electric kickboards, and similar devices. Rentals can be made through two channels:  
1. Own rental stores, where employees use a browser-based application for rentals and payments.  
2. Unoccupied stations around the city, where the customer retrieves and returns the device and pays through a mobile app.  

## Repository contents:
- Database and data warehouse schematics
- ETL script compatible with SSMS (etl_query.sql)
- Test script to check data warehouse integrity (eval.sql)
- AI-generated data for database
